1. システム構成
--------------------------------------------------------------------------------
1.1 コンポーネント
    - Seamless.dll      : Tsavorite 2.0.0-beta.3 バインディング
    - Benchmark         : BenchmarkDotNet ベースの計測ベンチマーク

1.2 名前空間
    - Seamless                  : ルート、Const など
    - Seamless.Collections      : 利用者公開コレクション、シリアライザ、
                                  IDictionary / IHashSet / ISet など
    - Seamless.Stores           : ストアファクトリ、HashStore / ListStore など
    - Seamless.Devices          : MemoryOnlyDevice などの IDevice 実装
    - Seamless.SessionFunctions : Tsavorite Session 用 Functions
    - Seamless.Linq             : 集合演算などの strategy 実装

2. 公開 API / 外部 I/F
--------------------------------------------------------------------------------
2.1 Store / HashStore
    Store.Create(...) は Store を返し、値型 readonly struct として構成
    パラメータを保持する。

    Create<TKey,TValue>(ManagedTag / UnmanagedTag) により、managed /
    unmanaged の組み合わせに応じた DictionaryStore を生成する。
    ストレージ併用版では IDevice LogDevice / ObjectLogDevice を追加で受け取る。

2.2 Store の役割
    - Create() で IDictionary / IHashSet / ISet 互換のコレクションを返す。
    - GetRecoveryEntryCount() で Recovery 後のエントリ数を取得する。
    - CompactLog(compactUntil) で Tsavorite ログをコンパクト化する。

2.3 Dictionary API
    - this[TKey key]
    - Add / TryAdd
    - ContainsKey / Contains
    - TryGetValue
    - Remove
    - Keys / Values
    - GetEnumerator
    - CopyTo
    - EntryCount / GetLongCount
    - IsDisposed
    - Refresh

2.4 HashSet API
    - Add
    - Contains / Remove
    - ExceptWith / IntersectWith / SymmetricExceptWith / UnionWith
    - IsSubsetOf / IsSupersetOf / IsProperSubsetOf / IsProperSupersetOf
    - Overlaps / SetEquals
    - GetEnumerator
    - CopyTo
    - EntryCount / GetLongCount / IsDisposed / Refresh

2.5 List API
    - ListStore.Create<T>(path, initialCapacity, initialDataCapacity, ManagedTag)
    - ListStore.Create<T>(path, initialCapacity, UnmanagedTag)
    - ManagedList<T> は index file と data file を使い、可変長レコードを格納する。

2.6 シリアライザ
    public interface ISerializer<T>{
        static abstract ReadOnlySpan<byte> Serialize(ref T value);
        static abstract T Deserialize(ReadOnlySpan<byte> bytes);
    }

    既定実装:
    - ManagedSerializer<T>   : MemoryPack を介する可変長シリアライズ
    - UnmanagedSerializer<T> : unmanaged 値の生メモリ直写し

2.7 Tag 構造体
    - ManagedTag
    - UnmanagedTag

3. 利用例
--------------------------------------------------------------------------------
    var hashStore = Store.Create();
    using var dictStore = hashStore.Create<int,string>(default(UnmanagedTag),
                                                       default(ManagedTag));
    using var dict = dictStore.Create();
    dict.Add(1, "a");
    dict.TryAdd(1, "b");
    dict.Refresh();

    using var listOwner = ListStore.Create<MyType>(@"C:\tmp\my.list");
    listOwner.Add(item);

4. 入出力
--------------------------------------------------------------------------------
4.1 入力
    - IndexSize などの構成パラメータ
    - IDevice 実装
    - CheckpointDir
    - シリアライザ実装

4.2 出力
    - コレクションインスタンス
    - Recovery メタデータ

4.3 例外
    - ArgumentNullException
    - ArgumentOutOfRangeException
    - InvalidOperationException
    - KeyNotFoundException
    - InvalidDataException
    - ObjectDisposedException
    - LogFull 状態

5. 設定パラメータ
--------------------------------------------------------------------------------
    - IndexSize
    - PageSize
    - SegmentSize
    - MemorySize
    - MutableFraction
    - StorageLimitFraction
    - StorageReserveBytes

6. 永続化レイアウト
--------------------------------------------------------------------------------
6.1 Tsavorite ログ
    IDevice 実装により永続化方式が決まる。

6.2 Checkpoint メタデータ
    - <CheckpointDir>/.seamless/<token:N>.index-size.json
    - <CheckpointDir>/.seamless/latest.index-size.json

6.3 ManagedList
    - <path>       : data file
    - <path>.index : record offset index file

7. エラーハンドリング方針
--------------------------------------------------------------------------------
    - Pending Status は CompletePending を実行し、IsCompleted を確認する。
    - LogFull 判定は書き込み前に行う。
    - Dispose 後の API 呼び出しは ObjectDisposedException 相当の挙動を取る。
