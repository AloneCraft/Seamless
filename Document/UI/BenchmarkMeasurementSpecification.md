# ベンチマーク計測仕様

## LoopCount校正

- 指定する測定時間は、1回あたりの表示時間ではなく、最終1バッチの合計実測時間である。
- LoopCountは比較行ごとに管理し、左列（FLinq）だけを校正対象とする。
- 左列が指定時間未満なら継続完了を表示してLoopCountを2倍にし、左列だけを再測定する。
- 左列が指定時間以上になったLoopCountを比較行の最終LoopCountとする。
- 右列（ZLinq）は最終LoopCountで一度だけ測定する。右列の合計時間が指定時間未満でも、成功なら完全完了である。
- 左右の最終LoopCountは同一でなければならない。失敗・例外・タイムアウトは完全完了に含めない。
- 左列が`int.MaxValue`でも指定時間未満なら、理由付き失敗にする。

## 表示と集計

- 時間セルは1回あたり時間を表示し、ツールチップで最終バッチ合計時間とLoopCountを表示する。
- CPU列の右側の`Loop`列は、左列校正中の現在値と、確定後の左右共通最終値を表示する。
- 上部の時間比・メモリ比は、選択中Runで実測済みの左右成功ペアのみから算出する。引継ぎ表示値や現在のチェック状態は集計対象にしない。
- 集計対象がない場合は比率を`-`と表示する。
