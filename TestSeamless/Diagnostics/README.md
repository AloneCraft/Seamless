# SSMSから開始するSQL Serverトレース

SSMSの画面操作は利用者が担当し、通常のSQL Serverで発行される初期化SQLを採取する。比較用SQLとは別の、SQL Server固有の診断操作である。ユーザーテーブルやスキーマを変更しない。

1. 比較元のlocalhostへ接続し、`Start-SsmsSqlTrace.sql`を実行する。イベントセッション管理権限が必要。
2. **実行後に、同じSSMSから新しいクエリを開く。** これにより、接続・クエリエディターの初期化文を採取する。その後、共通のAdventureWorks SQLやオブジェクト表示の操作を行う。
3. 完了を連絡する。表示されたTraceSession名があれば併せて伝える。こちらで結果を回収し、対象の一時セッションだけを停止・削除する。

採取開始をチャットの応答時刻へ合わせる必要はない。時間による自動終了はなく、SQL Server再起動後の自動開始もしない。同じクライアントPIDに対する重複開始は拒否する。SQLのLOGINパケットは採取せず、当該クライアントPIDのSQL_BATCHとRPCに限定する。SQL文に直接記述した値は記録されるため、この診断中は比較・初期化確認のSQLだけを使用する。

セッションバッファーとリングバッファーは各1MiB、リング内は最大1000イベントとする。古いイベントの上書きや切り詰めがある場合は、初期化文を完全に採取できたとは扱わない。結果の保存先はFとし、SQL Serverのファイル出力先を追加しない。

中止・手動終了時は、最初の結果に表示された正確な名前を使って次を実行する。他のトレースの名前を指定しない。

```sql
ALTER EVENT SESSION [表示されたTraceSession名] ON SERVER STATE = STOP;
DROP EVENT SESSION [表示されたTraceSession名] ON SERVER;
```
