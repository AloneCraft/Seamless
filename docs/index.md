# Seamless API リファレンス

**Seamless** は、.NET 向けの高パフォーマンスなインメモリ／永続化コレクション、ゼロアロケーション LINQ（FLinq）、およびインメモリ/ハイブリッド データベース ライブラリです。

## 主なパッケージ

- <xref:Seamless.Collections>: 高速・低オーバーヘッドなインメモリ コレクション群を提供します。
- <xref:Seamless.Collections.Persisted>: ディスク永続化に対応したコレクション実装を提供します。
- <xref:Seamless.Collections.Tsavorite>: Microsoft Tsavorite (FASTER) をベースとした高速な KVS / 永続化ストレージを提供します。
- <xref:Seamless.Linq>: ゼロアロケーション・インライン展開による超高速 LINQ 処理（FLinq）を提供します。
- <xref:Seamless.Database>: スキーマ定義・トランザクション・クエリ実行を備えた埋め込み型データベース機能を提供します。
- <xref:Seamless.Database.Rdbms>: リレーショナル データベース（SQL Server 等）との連携・コード生成機能を提供します。
- <xref:Seamless.Database.SqlServer>: SQL Server からのスキーマ読み込みやデータ移行をサポートします。
- <xref:Seamless.Execution>: クエリおよびタスクの並行・並列実行エンジンを提供します。
