# Benchmark UI グリッドの時間シェア/メモリシェア列レイアウト仕様

対象:
- Benchmark UI のベンチマーク結果グリッド(`Benchmark/Shared/UI/MainPage.cs` の `ベンチマークグリッド列を再構築`)

適用範囲:
- 2列タブ(最適化系: 書き換え/パイプライン融合/述語プッシュダウン、Scalable系: 今回/前回比較)
- 3列タブ(Array/IEnumerable/Range/List/Persisted/Tsavorite。左=FLinq、中央=ZLinqまたはValueLinq、右=System.Linq)

## 列順ルール

各プロジェクトブロックは、次の5列をこの順で**1つのプロジェクト見出し(スタックヘッダー)にまとめる**。

```
日時 → 時間 → 時間シェア → メモリ → メモリシェア
```

- 時間シェア・メモリシェアは、対応する「時間」「メモリ」の直後に置く(2列タブ・3列タブとも同一)。
- 時間シェア/メモリシェアを独立した列見出し(旧来の"左:右"のような単独スタックヘッダー)として分離しない。プロジェクト自体の見出し(タブの左見出し/中央見出し/右見出し)に含める。
- 一番右のブロック(2列タブの「右」、3列タブの「右」=System.Linq相当)は比較の基準側のため、時間シェア・メモリシェアを**持たない**。「日時,時間,メモリ」の3列のみ。

## 比較ペアのルール

- **2列タブ**: 左 vs 右 の1ペアのみ。左ブロックのシェア列は「左:右」の比率。
- **3列タブ**: 隣接列同士で2ペア。
  - 左ブロックのシェア列 = 「左 vs 中央」の比率
  - 中央ブロックのシェア列 = 「中央 vs 右」の比率
  - 右ブロックはシェア列を持たない(上記ルールの通り、基準側のため)
  - 全ての列を一番右(System.Linq)とだけ比較する旧仕様は誤りであり、隣接列同士の比較が正しい。

## 表示形式

- シェア値は `"0.35:0.65"` のような2値比率の文字列。左右の値の合計に対する割合(丸めは小数点2桁、四捨五入)。
- 各シェア列のセル下部に、比率に応じた幅の色付きバー(青=左側、オレンジ=右側)をゲージとして表示する。
- 時間シェアは、比較対象が基準(隣接列の相手)より3%を超えて遅い場合に `" ⚠"` を末尾に付与する。

## 実装箇所

- 列組み立て: [`Benchmark/Shared/UI/MainPage.cs`](../../Benchmark/Shared/UI/MainPage.cs) の `ベンチマークグリッド列を再構築` / `プロジェクト列とシェアを追加` / `プロジェクト列を追加` / `シェアゲージ列を作成` / `シェアゲージセルを作成`
- シェア値・ゲージ状態の計算: [`Shared/UI.Core/BenchmarkComparisonFormatter.cs`](../../Shared/UI.Core/BenchmarkComparisonFormatter.cs) の `時間シェアを計算` / `メモリシェアを計算` / `シェア値` / `ベンチマークシェアゲージ状態`
- 行モデル側のプロパティ: [`Benchmark/Shared/UI/BenchmarkRunnerModels.cs`](../../Benchmark/Shared/UI/BenchmarkRunnerModels.cs)
  - 2列タブ用(左vs右固定): `時間シェア表示` / `メモリシェア表示` / `時間シェアゲージ` / `メモリシェアゲージ`
  - 3列タブ用(隣接ペア): `左時間シェア表示` / `左メモリシェア表示` / `左時間シェアゲージ` / `左メモリシェアゲージ`(左vs中央)、`中央時間シェア表示` / `中央メモリシェア表示` / `中央時間シェアゲージ` / `中央メモリシェアゲージ`(中央vs右)
  - 旧「速度(x倍)」表示(`左速度文字列`/`中央速度文字列`/`速度を計算`/`速度を整形`)は廃止済み。

## 経緯

- `e956cd55` で2列タブ向けにシェアゲージ機構(比率+視覚バー)を導入。
- `c256b3ae`(3列タブ新設)の際、この機構を再利用せず「速度(x倍)」テキストを新設してしまい、2列タブと3列タブで表示形式が食い違った。
- 3列タブ側を2列タブの当時の列順(シェア列を独立ヘッダーとして左右ブロックの間に配置)に合わせる修正を一度行ったが、これは方向が逆だった。
- 最終的に、2列タブ側を3列タブの列順(シェアをプロジェクト自身の見出しに含める)に合わせて統一し、本仕様に確定した。
