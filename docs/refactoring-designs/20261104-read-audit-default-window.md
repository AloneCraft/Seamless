# 正常読み取り集計の既定期間

## 確定した仕様
利用者の回答により、通常の検索回数は利用者・DB・問い合わせ・コード版・権限版ごとに1分単位へまとめ、5秒ごとに保存する。集計期間と保存間隔は別の設定である。`20261104-read-audit-buffer.md`の期間未確定の記述を置き換える。

## 反映
`ReadAuditOptions`に1分・5秒の既定構成を追加する。既存の期間を受け取るコンストラクターと埋め込みサービスの明示オプション契約は維持する。通常のCLIサーバーは形式5でこの既定構成を使い、期間・保存間隔の明示値を優先する。保存間隔だけを指定した場合にも1分の既定期間を使う。管理者が明示的に停止する`--no-read-audit`も用意し、期間・間隔との矛盾した指定は拒否する。

形式3/4の領域を起動だけで更新しない。設定省略時は旧形式の収集を有効にせず、明示設定時には形式更新が必要と案内する。埋め込みサービスへnullのオプションを渡した場合は従来どおり収集しない。現在の権限版が取得できない入口ではnullを保持し、別の版番号で補わない。

## 検証
既定60秒と5秒、明示値の優先、保存間隔のみ、停止指定、旧形式、無効値を確認する。実際にCLIサーバーを既定で起動し、TLS経由で収集状態を取得する。既存のバッファ・検索・認可保存のテストも確認する。
