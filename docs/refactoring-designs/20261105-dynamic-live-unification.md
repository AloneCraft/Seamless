# ライブ検証への統合

利用者合意済み。ライブ検証を初期表示にし、通常実行の設定行とSystem・Seamlessの専用タブを統合する。履歴と既存の詳細・再実行を共用する。

## 検証対象

入力元・要素型は全選択から絞り込む。能力表に基づく44組み合わせについて、ペア、3段、ランダムの順に、最大16件ずつ巡回する。ランダム開始は直接選べる。ランダムの終了件数は入力元と型の組み合わせごとに指定し、空欄なら停止まで継続する。試行番号の区間を切り替えるときはSeedを決定的に導出する。

## 結果

段階、入力元、型、実装で集計と一覧を絞る。速度はSystem.Linq中央値と比較実装中央値の比を使い、悪い倍率から表示する。幾何平均は組み合わせを等重みとする。割り当て量は同じクエリ集合で平均し、0 Bを明示する。結果不一致と欠測を性能集計から除外する。個別結果から保存済みIRと条件を使って再実行する。

## 移行と検証

既存のWorkerプロトコルとDBを利用する。履歴条件の両形式を読み、旧履歴の再実行も検証する。全組み合わせの実行計画、有限・継続探索、集計、再実行、隔離GUIを確認する。
