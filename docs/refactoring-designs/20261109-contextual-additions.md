# 対象の近くから追加する共通操作

更新日 2026年11月9日

## 共通の操作

左ツリーのテーブル、システム、ロールと権限、利用者、サーバー設定、監査と、各管理画面の追加可能な子要素に、対象の近傍の`＋`から操作を選ぶ入口を設ける。

`追加メニューホスト`は既存の`対象操作ホスト`、`操作メニュー`、`コマンド登録`を組み合わせる。ホバー・フォーカス・タッチ時のハンドル、対象付近への配置、検索、キーボード操作、Escape、外側クリックは共通の実装へ接続する。利用できる操作と実行可能な状態は、コマンドの表示・実行条件から決定する。

フォーム内のハンドル、メニュー項目、サブメニュー、戻る操作には`type="button"`を指定する。追加操作からフォームの保存が発火しないようにする。処理中のロール行の選択も抑止する。

表示後に操作条件が変わった場合、管理操作の拒否・コマンドの状態不一致は同じメニュー対象を保持して`role="alert"`で案内する。取消は`role="status"`で通知する。成功したときにメニューを閉じ、未分類の例外は呼出元へ伝播させる。

表示対象のコマンドが一つもない場合は追加ハンドルを無効にし、メニューを開かない。実行可否だけが一時的に変わったコマンドは従来どおり表示する。組み込み実行で任意のサーバー設定がすべて利用不可の場合も同じ条件を使う。

## 実際の編集先

| 対象 | 追加操作と既存機能への接続 |
| --- | --- |
| テーブル | 列追加は既存のグリッドへ重複しない仮列名を追加する。主キーは同じグリッドの主キーチェックを編集する。編集中の同じテーブルへの反復追加は入力を保持する。別の入力中の定義がある場合は反映を促す。下書きへの反映・検証・公開は明示操作で行う |
| 外部キー | `DatabaseDesigner`の外部キー定義はテーブル宣言プロパティの属性へ接続している。専用の外部キー作成フォームは現在ないため、メニューは該当ファイルのC#編集を開く |
| ロール | ロール作成、対象資源の規則追加、利用者・グループの割り当て入力を開く。選択中のロールを保持し、別ロールの未保存編集を保護する。規則・割り当ては元の共通認可APIへ明示保存する |
| 利用者 | 利用者作成、選択した利用者のDB権限追加を既存の入力へ接続する。別の利用者の未保存編集と保存中の操作を保護する |
| サーバー設定 | 設定項目は固定した契約を持つ。追加メニューは受信・送信予算、応答期限、外部ブラウザー受付の既存任意入力を展開する。起動引数の固定項目と実行形態で利用できない項目を除外する。具体的な値は利用者が入力して保存する |
| 監査 | DB、利用者、UTC期間、操作、結果の検索条件を段階的に追加する。既に値を持つ条件は表示し続ける。転記状態から検索条件を追加するとイベント検索へ移る |

システム全体の追加入口も、同じ管理画面と共通APIへ接続する。認可の最終判定は保存・取得のサーバー側処理で行う。

## DB読み込み中の操作状態

DBの定義と個人下書きは非同期に取得する。同じDBを重ねて開いたときは、先に画面へ接続した文書を保持し、その後の読み込み結果で編集中の文書を置換しない。別DBへ移動してから前のDBの読み込みが完了しても、選択DB・表示中のタブ・現在のDBの案内を戻さない。

`Tests/Management.Tests/ManagerDatabaseLoading.cs`はTCSで読み込みの完了順を固定し、同じDBの二重読み込みと、異なるDBの順方向・逆方向の完了を検査する3ケース。旧実装のawait後の`Dictionary.Add`と無条件の案内更新に対応する回帰で、Windows Debug近接46件に含めて3ケースとも成功した。証拠は`near-debug-r16/checks.trx`。通常のUI読取経路は維持し、追加の読み込み待機キューは設けていない。実ブラウザーでの同じ遅延条件と最新候補のReleaseは未検証。

## 左ツリーの展開と折り畳み

DB、スキーマ、テーブル・ビュー・関数の分類行に共通の開閉ボタンを置く。ボタンは常時表示し、Tabでフォーカスを移せる。Enter・Spaceで切り替え、左右矢印キーでは右が展開、左が折り畳みとなる。行の追加・操作メニューと名称選択は、それぞれ既存の入口を使用する。

DBの展開は定義と下書きの読み取りだけを行い、右側の編集対象、未保存の入力、開いている文書タブを切り替えない。複数DBを同時に展開でき、子項目を選んだときに所属DBへ移る。開閉状態はDBの内部IDごとにワークスペース内で保持する。親を閉じて再び開いても、スキーマ・分類それぞれの開閉状態を維持する。ブラウザーの再読み込み後は初期状態に戻る。

`Tests/Management.Tests/TreeExpansion.cs`へ、所属別の分類とスキーマの独立開閉、左右キー、別DB展開時の編集保持、読込中に閉じた状態の保持という4ケースを追加した。ソース実装とリソースXMLの確認までを完了し、コンパイル・近接試験・実ブラウザー確認は次の固定候補で行う。
