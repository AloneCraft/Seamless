# 専用DBプロジェクトのローカルパッケージ参照

## 維持する契約と修正理由

新規DBの専用C#プロジェクトはローカルパッケージを参照する。Windows固定の絶対パスとXML文字列への直接埋め込みを修正し、Linuxでも存在するフィードと、特殊文字を扱えるNuGet.Configを生成する。配布物の対応版を選択する方式は[サーバーと専用C#プロジェクトのパッケージ対応](20261109-source-package-cohort.md)へ引き継ぐ。マニフェストがない従来フィードの既定版は0.0.0とする。

DBの保存とソースプロジェクトの保存は独立した操作とする。既存プロジェクトのNuGet.Configと参照先を自動変更しない。新規生成は空の保存先だけに許可する。

## 解決と失敗の扱い

明示されたフィード、SEAMLESS_PACKAGE_FEED、ホスト配置のpackages、従来のホスト相対Work/VirtualDbFeed、開発・検証環境で指定したSEAMLESS_SOURCE_REPOSITORY、現在の作業ディレクトリから特定したSeamlessリポジトリのWork/VirtualDbFeedの順で解決する。明示フィードの不存在は構成エラーとする。リポジトリ候補はSeamless.slnxを確認し、存在するフィードだけを使う。

固定開発版に必要なフィードが見つからない場合は、プロジェクトを生成する前に設定方法を案内する。OS固有の存在しないドライブパスを生成しない。NuGet.Configは既存のXML APIで構築し、特殊文字をエスケープする。現在のSeamless専用ソースマッピングとnuget.orgの併用を維持する。

## 確認

特殊文字を含む明示フィードを持つ新規プロジェクト、存在しない明示フィードの拒否と保存先の保持、既定の生成プロジェクトのネイティブ絶対パスを近接試験で確認する。Linuxの生成・SDKビルド・成果物取り込みは同じフィードのパッケージと依存DLLを照合して確認する。パッケージ自体の最終配布はW13へ引き継ぐ。
