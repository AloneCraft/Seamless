# 03 機能別の契約

機能群ごとに、ご指定の10項目を書きます。[02](02_不変条件と禁止事項.md) の INV・NG と、[06](06_検証と受け入れ.md) の AC は ID だけを示し、ここには機能固有の点だけを書きます。「変更範囲」と「非対象」は、その機能を直すときに触ってよい範囲です。

---

## D. LINQ ランタイムと大規模 LINQ（F-05、F-06）

| 項目 | 内容 |
|---|---|
| 不変条件 | INV-01、02、03、04、12。追加：外部ソートは安定。グループはキーの初出順と要素順、Join は外側の順序を保つ。1つの巨大なグループでも全件を1つの `List<T>` に入れない |
| 禁止事項 | NG-02、03。追加：比較子を省略したとき、ハッシュだけで等しいと判断しない（衝突時はバイト列で照合する） |
| 前提条件 | 退避には決定的な Codec が要る。一般クラスはクエリの実行前に明示登録する |
| 変更範囲 | `Seamless.Linq/Scoped*.cs`、`ExternalSort.cs`、`DiskLookup.cs`、`Seamless.Linq.Analyzers/*`。値列挙の演算子は FLinq の呼び先なので、E と一緒に扱う |
| 非対象 | スコープ外の通常 LINQ の意味。並列クエリ |
| 完了条件 | スコープ付きクエリで使える演算子の一覧があり、一覧外を使うとコンパイル時か実行時に理由つきで失敗する（G-05） |
| 検証項目 | AC-LINQ、AC-RESOURCE、AC-LIFETIME。`Execution.Tests/ScopedQuery.cs`（8件） |
| 移行条件 | 一覧外の演算子を禁止する診断は、まず警告で入れ、既存の利用箇所をなくしてからエラーにする |
| ロールバック条件 | 追加した演算子が通常 LINQ と結果・順序で一致しなければ、その演算子を外して禁止側へ戻す |
| 既知の問題 | `ScopedQuery<T>` は `IEnumerable<T>` を実装するので、持たない演算子（`GroupJoin`、`Reverse`、`Last`、集計など）は `System.Linq` 側に解決され、予算の外で全件メモリ処理になりうる（推測・高、G-05）。`ToList`/`ToArray` の予約量は推定値 |
