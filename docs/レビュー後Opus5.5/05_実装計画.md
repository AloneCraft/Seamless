# 05 実装計画

## 優先順位の決め方

ユーザーの回答 Q-01（2026-09-25、Atras 版で確定）に従い、次の順に進めます。

1. **正しさ・データ保全**：誤った結果、データ損失、終了不能、予算の迂回をなくす。
2. **検証の再現性**：テストと計測の結果を信用できる状態にする（古い成果物・不安定なテスト・基準のない比較をなくす）。
3. **明確な機能不足**：未実装・統合不足を埋める。
4. **性能と保守性**：正しさと測り方がそろってから行う。
5. **出荷**：配布・文書・全体の回帰。

過去の遅い計測値の大きさだけで優先度を決めません。いま再現しない過去の不具合を、修正対象として扱いません。
