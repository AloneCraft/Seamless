# 07 判断事項

コードを調べれば答えが出ることは質問しません。ここに残すのは、製品の範囲・互換性・人の操作に関わる判断だけです。AGENTS.md に従い、質問は1つずつ行います。回答のない項目を承認済みとして扱いません（NG-12）。
